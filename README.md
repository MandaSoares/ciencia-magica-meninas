# Conscientistas

Plataforma educacional gratuita para meninas aprenderem sobre Ciencia, Tecnologia, Engenharia e Matematica (STEM) de forma interativa e gamificada.

## Tecnologias

- React + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Supabase (auth, database, storage)
- React Query

## Como rodar

```sh
npm install
npm run dev
```

## Estrutura

- **Trilhas** - Conteudos introdutorios (estilo Duolingo)
- **Modulos** - Cursos completos com projetos e certificados
- **Laboratorio Virtual** - Experimentos praticos
- **Areas de Atuacao** - Carreiras STEM e mulheres inspiradoras
- **Blog** - Artigos e dicas sobre STEM
